# מקליט מסך

דף אחד להקלטת מסך בדפדפן. אין התקנה, אין שרת, אין העלאה לשום מקום — ההקלטה נשארת במחשב.

## שימוש

פתח את `index.html` בדפדפן (Chrome או Edge), לחץ "התחל הקלטה", בחר מסך או חלון, ובסוף לחץ "עצור" והורד את קובץ ה-WebM.

## דרישות

דפדפן שתומך ב-`getDisplayMedia` וב-`MediaRecorder`. הקלטת אודיו של המערכת נתמכת ב-Chrome ו-Edge בלבד.
